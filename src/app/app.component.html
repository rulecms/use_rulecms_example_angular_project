This is a demonstration of how to integrate RuleCMS widgets into an Angular application

Demo RuleCMS Widget

The widget below is rendered using the rulecms-widget component from the @rulecms/widget-angular package, with @rulecms/source-components-angular registered as the default component library.

Getting Started

If you are seeing an error below, replace the demo published key and app token in src/app/rulecms-config.ts with values from your RuleCMS.com account.

Integration Steps

  1. Install the packages: npm install @rulecms/widget-angular @rulecms/source-components-angular
  2. Wrap your app with rulecms-widget-provider and register {{ '{ default: sourceComponents }' }}
  3. Add rulecms-widget with your published key
  4. That is it. Your widget is now integrated and ready to display

Next Steps

  • Replace the demo published key with your actual widget published key
  • Set your app token in src/app/rulecms-config.ts
  • Create and publish more widgets in the RuleCMS composer
  • Explore RuleCMS widgets in your own Angular applications
